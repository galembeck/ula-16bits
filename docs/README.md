Uso de IA:
   - Quais partes foram desenvolvidas com uso de IA e por quê?

- Resposta:
   - A decisão entre utilizar nível de circuito lógico ou bibliotecas como "numeric_std" foi tomada com a ajuda da IA, pois, diferentemente do projeto da disciplina de Projeto de Sistemas Digitais, neste projeto prático, poderíamos utilizar bibliotecas que nos auxiliariam no desenvolvimento e realização de operações, reduzindo o tempo de desenvolvimento e também de execução das operações.
   - Documentações e partes técnicas como "register_16bits.vhd", "register_bank.vhd" e "extenders.vhd" e "multiplexers.vhd" foram desenvolvidas com AUXÍLIO de IA, e não completamente pela IA, uma vez que arquivos como esses são técnicos e exigem certo conhecimento da parte lógica (a fundo) de uma ULA. Portanto, fomos assistidos durante o desenvolvimento com conhecimento técnico suficiente para "tradução" do que acontece no circuito para o código em si.
